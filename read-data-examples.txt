HOW ADMIN ADDS THESE QUESTIONS
-------------------------------

Step 1: Select Instruction Type
→ "Read the Data and answer the question"

Step 2: Upload Image
→ Click upload area
→ Select image file (population-table.png)
→ Preview appears

Step 3: Add Questions
→ Click "Add Question" for each question
→ Fill in question text
→ Fill in answer text
→ Can add unlimited questions

Step 4: Set Details
→ Total Marks: 5
→ Difficulty: Medium

Step 5: Submit
→ Click "Add Read Data Question"
→ Image uploads to Supabase Storage
→ Question saves to database
→ Done!
